# Diabetes Analysis Dashboard

This project is an interactive Excel dashboard developed to analyze diabetes-related data and identify patterns, trends, relationships, and key insights from patient-level information.

## 📊 Project Overview

The dataset contains information related to diabetes and includes variables such as:

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age
* Outcome

## 🎯 Key Analysis

The dashboard focuses on:

* Diabetes outcome analysis
* Diabetes rate by age groups
* Glucose level analysis
* BMI analysis
* Blood pressure analysis
* Insulin analysis
* Age-wise diabetes patterns
* Comparison of diabetic and non-diabetic patients
* Variable-level analysis
* Relationship and correlation analysis
* KPI-based insights

## 🛠️ Tools & Techniques

* Microsoft Excel

## 🎯 Objective

The objective of this project is to transform diabetes-related patient data into an interactive Excel dashboard and use data-driven analysis to identify meaningful patterns and factors associated with diabetes outcomes.

The dashboard is designed to present complex data in a clear and interactive format while supporting analytical decision-making.
