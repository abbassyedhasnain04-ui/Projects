# Heart Disease Dashboard Project

This project is an interactive Excel dashboard developed to analyze heart disease data and identify patterns, relationships, and meaningful health-related insights within the dataset.

## 📊 Project Overview

The dataset contains patient-level information including:

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Resting ECG
* Maximum Heart Rate
* Exercise-Induced Angina
* ST Depression
* ST Slope
* Number of Major Vessels
* Thalassemia
* Heart Disease Target

## 🎯 Key Analysis

The project focuses on:

* Heart disease prevalence
* Disease rate by age groups
* Comparison between patients with and without heart disease
* Variable-level analysis
* Correlation analysis
* Difference analysis
* Identification of important variables
* KPI-based insights
* Interactive dashboard analysis

## 🎯 Objective

The objective of this project is to transform patient-level heart disease data into an interactive analytical dashboard and use data-driven methods to identify patterns and relationships associated with heart disease.
