# House Property Dashboard

An interactive Excel dashboard developed to analyze house property data and identify meaningful patterns, trends, and business insights.

## 📊 Dashboard Overview

The dashboard provides an interactive analysis of property characteristics and property activity using:

* Property Price
* Area (sq ft)
* Property Age
* Bedrooms
* Bathrooms
* Distance from City (km)
* Location Score

## 📌 Key Features

* Interactive KPI cards
* Pivot Tables and Pivot Charts
* Interactive Slicers
* Dynamic filtering
* Property activity analysis
* Distance and location analysis
* Bedroom and bathroom analysis
* Location score analysis
* Continuity analysis across distance zones
* Dashboard reset functionality using VBA
* Business-focused insights

## 🛠️ Tools & Techniques

* Microsoft Excel
* Excel Formulas
* Pivot Tables
* Pivot Charts
* Slicers
* Power Query
* VBA
* Dashboard Design
* KPI Analysis

## 📈 Key Analysis

The dashboard helps identify:

* Best and worst distance zones
* Property activity across distance ranges
* Location score patterns
* Impact of bedrooms and bathrooms on property activity
* Continuity of location scores across distance zones
* Areas with significant changes in property activity

## 📁 File

**House Property Dashboard.xlsm**

The `.xlsm` file contains the interactive Excel dashboard along with VBA functionality.

## 🎯 Objective

The objective of this dashboard is to transform raw house property data into an interactive analytical tool that supports data-driven decision-making and provides clear business insights.
