# House Property Dashboard Project

This project is an interactive Excel dashboard developed to analyze house property data and identify patterns, trends, and business insights.

## 📊 Project Overview

The dataset contains information about residential properties, including:

* Property Price
* Area (sq ft)
* Property Age
* Bedrooms
* Bathrooms
* Distance from City (km)
* Location Score

The dashboard analyzes property activity and helps identify how factors such as location, distance, bedrooms, bathrooms, and property characteristics influence property sales and activity.

## 🎯 Key Analysis

The project focuses on:

* Property activity by distance from the city
* Location score analysis
* Bedroom and bathroom analysis
* Property distribution across distance zones
* Continuity of location scores within distance zones
* Identification of high- and low-performing zones
* KPI-based business insights
* Interactive filtering using slicers

## 🛠️ Tools & Techniques

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Power Query
* Excel Formulas
* VBA
* Dashboard Design
* KPI Analysis
