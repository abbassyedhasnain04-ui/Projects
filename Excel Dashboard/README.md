# Excel Dashboard Projects

This folder contains my Excel dashboard projects created for data analysis, visualization, and business insights.

## Projects

### House Property Dashboard

An interactive Excel dashboard for analyzing house property data, including:

* Property Price
* Area
* Bedrooms
* Bathrooms
* Property Age
* Distance from City
* Location Score

The project focuses on data analysis, KPI development, interactive slicers, dashboard visualization, and business insights.
